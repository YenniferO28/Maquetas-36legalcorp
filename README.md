## Publicar con GitHub Pages
1. Sube todos los archivos a la raíz de un repositorio.
2. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. En unos minutos la maqueta queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Un repositorio privado solo se publica con Pages en ciertos planes de GitHub. Si el cliente no tiene cuenta, el repositorio debe ser público (o usa otro alojamiento estático).
